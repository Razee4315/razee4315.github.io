# 01 Brief

**Site:** https://razee4315.github.io/ (repo Razee4315/razee4315.github.io, GitHub Pages legacy mode, static, no build).
**Job:** a personal hub that hands visitors off to one of five free, open-source projects, and makes the owner memorable.
**Primary action:** click through to a project. Secondary: GitHub profile.
**Audience:** developers and makers arriving from Reddit, GitHub, launch posts and search; roughly half on phones.

**Projects (facts checked 2026-09-28 via the GitHub API):**

| Code | Project | What it is | Platforms | Licence |
|---|---|---|---|---|
| SF-01 | Snipflag | Visual bug reporting for Linear | Windows, macOS, Linux | MIT |
| PL-02 | Paperling | Markdown editor with live preview | Desktop, Android | Apache-2.0 |
| PW-03 | Paperwren | Document viewer (PDF, Word, Excel, PowerPoint) | Android, Windows | MIT |
| VM-04 | Vuoom | Screen recorder with auto-zoom | Windows | Apache-2.0 |
| CF-05 | coldframe | Remotion renders on GitHub Actions | GitHub Actions | MIT |

**Success criteria:** every project reachable in one click from the first screen or one short scroll; the page is remembered ("the site with the birds"); fast on a mid-range phone; works with keyboard and reduced motion.

**Non-goals:** blog, email capture, analytics, dark mode, contact form, other Pages projects (owner chose these five), an email address (owner chose GitHub + LinkedIn only).
