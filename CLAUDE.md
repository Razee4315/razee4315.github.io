# razee4315.github.io rulebook

Static hub for Saqlain Razee's projects. docs/ is law (02 art direction, 03 tokens, 05 motion, 06 pages). Keep intact: robots.txt Sitemap lines, the IndexNow key file, the Google verification file, tools/indexnow.py and its workflow.

## Forbidden
No indigo or violet. No gradient text. No Inter. No three-card grids. No card borders. No soft drop shadows. No bounce or elastic easing. No emoji (draw symbols as SVG). No stock photography. No dark mode. No preloader. No border-radius except drawn scene shapes.

## Required
Palette and type per docs/03. Easing expo.out by default. Every animation has a reduced-motion path inside gsap.matchMedia. Every interactive element has :focus-visible. Pinned CDN versions: gsap 3.13.0, lenis 1.3.11.
Signature: the wren tree (up to 10 birds, flight, talk, Snipflag bracket moment).
